# Data Quality Control Center

An interactive data quality dashboard built with Python and Streamlit to demonstrate data cleaning, validation, issue tracking, and before-and-after quality analysis.

## Features

- Upload CSV or Excel datasets
- Simulated sample datasets for demonstration
- Overall quality score
- Completeness analysis
- Duplicate detection
- Formatting consistency checks
- Numeric range validation
- Quality issue breakdown
- Before vs after cleaning comparison
- Validation check summary
- Cleaned data preview
- Download cleaned data as CSV

## Technologies

Python, Pandas, NumPy, Plotly, Streamlit

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data Disclaimer

Sample data is simulated for portfolio and demonstration purposes. Uploaded files are processed by the running Streamlit application and are not intentionally stored by this project.
